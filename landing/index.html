Quick actions

Six actions above the tab list, each one a single click.

Every action is individually toggleable in Settings - keep the two you use, hide the rest.

QUICK ACTIONS BAR

  • Tidy - group tabs by site and reorder in one pass.

  • Collapse - fold or expand every tab group.

  • Screenshot - capture the current tab to your chosen folder.

  • Pause all - mute every tab playing audio, at once.

  • Copy URLs - every open tab's link, one paste away.

  • Freeze - suspend background tabs and give memory back.

Install

Five steps, no Chrome Web Store review to wait on.

  1. Download

    Grab the latest zip from the Releases page, or clone the repo.

  2. Unzip

    Extract it anywhere - no build step, it's plain HTML/CSS/JS.

  3. Enable developer mode

    Open chrome://extensions and flip the toggle, top right.

  4. Load unpacked

    Click Load unpacked and select the extracted folder.

  5. Open the panel

    Click the extension icon, or press Ctrl+Alt+S.
